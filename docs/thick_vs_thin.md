# Thin vs thick equivalence (small-T limit)

Generated by `tests/compare_thick_thin.py`.

> **Note (2026-08-26).** The `Hamilton_mc_(thick)` rows below are the single-crystal
> Hamiltonian, which is now the `Hamiltonian` component at $(A,A_m,A_h)=(1,1,1)$
> — the same spectrum. The amplitude-convention fix of that revision transposes
> the per-line matrices, which is exactly nothing in the thin limit, so the
> $T=0.001$ columns are unchanged; the illustrative $T=1$ column can move in its
> last digits (for a single layer the transpose is visible only through the
> absorptive/dispersive commutator, ~0.1 % of the line depth — thick_models.md
> §2.6.2).

Each thick model at orientation $(\theta_h,\varphi_h)$ is compared to its thin twin with asymmetry $A=2\cos^2\beta/(1+\cos^2\beta)$, $\cos\beta=\sin\theta_h\cos\varphi_h$ (Hamilton: same $(\theta,\varphi)$, no $A$). All other parameters identical. Effective thickness $T=0.001$; spectrum on 600 points over $[-12,12]$ mm/s.

The Faraday-active rows (Sextet, MDGD, Relax_2S) were taken at the magnetized single crystal, $A_m=1$ (magnetic polar order $S_1=1$; see thick_models.md §3.2). $A_m$ has **no effect on the small-$T$ equivalence** — the Faraday term is off-diagonal and traceless in the thin limit — so the $T=0.001$ columns are unchanged for any $A_m$; only the illustrative $T=1$ column depends on it.
